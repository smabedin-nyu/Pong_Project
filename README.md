# Pong_Project

Created for CS3113

This is my Project for a Simple 2D Scene: Football (Soccer) Match 


Here, I have coded a classic style Pong Project, with my Theme being football, with a red player and a blue player.


Controls:

R-> Restart Game: This will set the score to 0-0, restore Player 2's input, and set the number of balls on the screen to 1

Q-> Quit Game: This will terminate the game, close the window, and start shutting down the assets

T-> Toggle Single/Double Player: This will either turn player 2's input on or off, replacing their inputs with an "AI" that just moves up and down

1/2/3-> Number of Balls: Hitting the number will generate the corresponding number of balls in game

W/S-> Player 1 Up/Down: This will move player 1 up or down

UpArrow/DownArrow-> Player 2 Up/Down: If player 2 is playing, this will move them up or down
